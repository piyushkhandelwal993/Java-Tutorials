## 1️⃣ What is a Literal? (Foundation Concept)

### 🧠 Simple Explanation

A **literal** is a **fixed value written directly in the code**.

```java
int x = 10;
```

Here:

* `x` → variable
* `=` → assignment
* `10` → **literal**

📌 **Literal = Data itself**, not a variable.

---

### ❓ Why Literals Matter

* They define **data types**
* They affect **memory**
* They influence **compiler behavior**
* Many **interview trick questions** come from literals

---

### 🔍 Types of Literals in Java

| Literal Type   | Example             |
| -------------- | ------------------- |
| Integer        | `10`, `0xFF`, `101` |
| Floating-point | `10.5`, `2.3e3`     |
| Boolean        | `true`, `false`     |
| Character      | `'A'`, `'\n'`       |
| String         | `"Hello"`           |

## 2️⃣ Integer Literals

### ✔ Definition

Whole numbers **without decimal points**.

```java
int a = 10;
```

---

### 📌 Number Systems Supported

Java allows **4 formats**:

| System      | Prefix | Example  |
| ----------- | ------ | -------- |
| Decimal     | none   | `10`     |
| Binary      | `0b`   | `0b1010` |
| Octal       | `0`    | `012`    |
| Hexadecimal | `0x`   | `0xA`    |

```java
int a = 10;      // Decimal
int b = 0b1010; // Binary
int c = 012;    // Octal
int d = 0xA;    // Hexadecimal
```

✔ All above values = **10**

---

### ⚠ Interview Trap: Octal Confusion

```java
int x = 08; // ❌ Compile-time error
```

Why?

* Octal digits range **0–7**
* `8` is invalid

---

### 🔹 Default Type of Integer Literal

```java
int a = 10;    // OK
long b = 10;  // OK
```

📌 **By default → int**

---

### 🔴 Long Literal Rule

```java
long x = 10000000000; // ❌ error
long y = 10000000000L; // ✔
```

📌 **Always append `L` or `l`**

✔ Best practice → use **capital L**

---

### 🧠 Edge Case (Interview Favorite)

```java
byte b = 10;   // ✔
byte c = 128;  // ❌
```

Why?

* `10` fits into byte range
* `128` does not

📌 **Compiler checks range at compile time**

---

### ✔ Checkpoint Questions

1. What is the default type of an integer literal?
2. Why does `int x = 09;` fail?
3. Difference between `0xA` and `0b1010`?
4. Why do we add `L` for long literals?

## 3️⃣ Floating-Point Literals

### ✔ Definition

Numbers with **decimal points or exponential form**.

```java
double d = 10.5;
```

---

### 🔹 Default Type

📌 **Floating literals are `double` by default**

```java
float f = 10.5;   // ❌
float f = 10.5f; // ✔
```

---

### ✔ Correct Ways

```java
double d1 = 10.5;
float f1 = 10.5f;
double d2 = 1.2e3; // 1200.0
```

---

### ⚠ Precision Issue (Interview Classic)

```java
System.out.println(0.1 + 0.2); // 0.30000000000000004
```

Why?

* Floating numbers use **binary approximation**
* Not all decimals can be represented exactly

📌 Important for **finance / banking systems**

---

### ❌ Invalid Floating Literals

```java
double d = 10.5D; // ✔
double d = .5;    // ✔
double d = 10.;   // ✔
double d = 10.5.3; // ❌
```

---

### ✔ Checkpoint Questions

1. Why does float require `f` suffix?
2. What is exponential notation?
3. Why floating-point math is imprecise?
4. Difference between `float` and `double`?

## 4️⃣ Boolean Literals

### ✔ Only Two Values

```java
boolean a = true;
boolean b = false;
```

📌 **Lowercase only**

---

### ❌ Common Beginner Mistakes

```java
boolean x = True;  // ❌
boolean y = 1;     // ❌
```

Java is **not C/C++**

---

### ✔ Interview Trick

```java
if (true == true) { } // ✔
if (true == 1) { }   // ❌
```

---

### ✔ Checkpoint Questions

1. How many boolean literals exist in Java?
2. Is `0` considered false?
3. Is boolean size JVM dependent?

## 5️⃣ Character Literals

### ✔ Definition

Single character enclosed in **single quotes**

```java
char c = 'A';
```

---

### 🔹 Unicode Support

Java characters are **Unicode (16-bit)**

```java
char c = '\u0041'; // 'A'
```

---

### 🔹 Escape Characters

| Escape | Meaning      |
| ------ | ------------ |
| `\n`   | New line     |
| `\t`   | Tab          |
| `\'`   | Single quote |
| `\\`   | Backslash    |

---

### ⚠ Interview Trap

```java
char c = 65;
System.out.println(c); // A
```

Why?

* `char` is internally an integer (Unicode value)

---

### ❌ Invalid

```java
char c = 'AB'; // ❌
char c = "A";  // ❌
```

---

### ✔ Checkpoint Questions

1. Why char uses single quotes?
2. Can char store numbers?
3. What is Unicode?

## 6️⃣ String Literals (Most Important 🔥)

### ✔ Definition

Sequence of characters enclosed in **double quotes**

```java
String s = "Java";
```

---

### 🧠 String Pool Concept (Interview Gold)

```java
String s1 = "Java";
String s2 = "Java";
```

✔ Both point to **same memory**

```java
String s3 = new String("Java");
```

❌ New object created

---

### 🔥 Comparison Trap

```java
s1 == s2 // true
s1 == s3 // false
```

✔ Always use:

```java
s1.equals(s3)
```

---

### ⚠ Immutability

```java
String s = "Java";
s.concat(" World");
System.out.println(s); // Java
```

📌 String is **immutable**

---

### ✔ Special Cases

```java
String s = null; // ✔
String s = "";   // empty string
```

Difference matters in interviews.

---

### ✔ Checkpoint Questions

1. Difference between `==` and `equals()`
2. What is String pool?
3. Why String is immutable?
4. Difference between `null` and `""`
