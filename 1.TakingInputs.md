# 🧪 Step 3: Using `Scanner` (Beginner Friendly) (45 mins)

### 3.1 Import & Create Scanner Object

```java
import java.util.Scanner;

Scanner sc = new Scanner(System.in);
```

Explain:

* `System.in` → keyboard input stream
* `Scanner` parses input into data types

---

### 3.2 Taking Primitive Data Types

#### int

```java
int age = sc.nextInt();
```

#### double

```java
double salary = sc.nextDouble();
```

#### boolean

```java
boolean isActive = sc.nextBoolean();
```

#### String (single word)

```java
String name = sc.next();
```

#### String (full line)

```java
String address = sc.nextLine();
```

---

### ⚠️ VERY IMPORTANT TRICKY CONCEPT (Interview Favorite)

```java
int age = sc.nextInt();
String name = sc.nextLine(); // BUG
```

❌ `name` becomes empty

### ✅ Correct Way

```java
int age = sc.nextInt();
sc.nextLine(); // consume leftover newline
String name = sc.nextLine();
```

👉 **WHY?**

* `nextInt()` leaves `\n` in buffer
* `nextLine()` immediately consumes it

📌 **Interview Question**:

> Why does `nextLine()` get skipped after `nextInt()`?

---

### 3.3 Taking Array Input (Multiple Values)

#### Array of int (one per line)

```java
int[] arr = new int[5];
for(int i = 0; i < arr.length; i++) {
    arr[i] = sc.nextInt();
}
```

---

### 3.4 Array of int (Single Line Input)

Input:

```
10 20 30 40 50
```

```java
int n = sc.nextInt();
int[] arr = new int[n];

for(int i = 0; i < n; i++) {
    arr[i] = sc.nextInt();
}
```

---

### 3.5 Array of String (Single Line)

Input:

```
Java Python C++ Go
```

```java
sc.nextLine(); // safety
String line = sc.nextLine();
String[] languages = line.split(" ");
```

👉 `split(" ")` is **very important for interviews**

---

### ❌ Common Scanner Exceptions

| Exception                | Cause           |
| ------------------------ | --------------- |
| `InputMismatchException` | Wrong data type |
| `NoSuchElementException` | Input exhausted |
| `IllegalStateException`  | Scanner closed  |

Example:

```java
int x = sc.nextInt(); // user enters "abc"
```

---

### ✅ Best Practices with Scanner

* Always validate input
* Close scanner **only at program end**
* Avoid mixing `next()` and `nextLine()` blindly

# 🧠 Step 4: Using `BufferedReader` (Interview Level) (45 mins)

### 4.1 Why BufferedReader?

Explain:

* Faster than Scanner
* Used in **competitive programming**
* Preferred in interviews

---

### 4.2 Setup

```java
import java.io.*;

BufferedReader br = new BufferedReader(
    new InputStreamReader(System.in)
);
```

---

### 4.3 Taking Input (Everything is String)

```java
String input = br.readLine();
```

Conversion required:

```java
int x = Integer.parseInt(input);
double d = Double.parseDouble(br.readLine());
```

---

### 4.4 Array Input in Single Line

Input:

```
1 2 3 4 5
```

```java
String[] parts = br.readLine().split(" ");
int[] arr = new int[parts.length];

for(int i = 0; i < parts.length; i++) {
    arr[i] = Integer.parseInt(parts[i]);
}
```

---

### ⚠️ Tricky Edge Cases

* `NumberFormatException`
* Extra spaces → use `split("\\s+")`

```java
String[] parts = line.trim().split("\\s+");
```

# 🧠 Step 5: Using `Console` (Security Focus) (15 mins)

```java
Console con = System.console();
String username = con.readLine();
char[] password = con.readPassword();
```

👉 Password is **not visible on screen**

⚠️ **Does NOT work in IDEs**
✔ Works in terminal

# 🎤 Interview Traps to Warn Students About

* Mixing `nextInt()` and `nextLine()`
* Forgetting `parseInt()`
* Not handling `NumberFormatException`
* Using Scanner for high-performance apps
* Closing `System.in` too early
