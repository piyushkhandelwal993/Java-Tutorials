
# **Java Type Casting, Type Promotion & Automatic Type Conversion**

## **1. Why This Topic Is Extremely Important (5 mins)**

Before learning *what* type casting is, students must know **why it exists**.

### Real-world analogy

* You can pour **1 liter bottle** into a **5 liter bucket** easily.
* But you **cannot pour 5 liters into 1 liter bottle** without loss/spillage.

👉 Java behaves **exactly the same** with data types.

---

## **2. Java Data Type Size Hierarchy (Foundation) (10 mins)**

Before casting, students MUST remember sizes.

```
byte   → 1 byte
short  → 2 bytes
int    → 4 bytes
long   → 8 bytes
float  → 4 bytes
double → 8 bytes
char   → 2 bytes (Unicode)
boolean → JVM dependent (not castable)
```

### Numeric Promotion Order (Very Important)

```
byte → short → int → long → float → double
```

👉 **Interview Rule #1**:
Java always promotes **smaller data types to larger ones automatically**, never the opposite.

---

## **3. Automatic Type Conversion (Widening) (15 mins)**

### Definition

When **smaller data type is assigned to a larger data type**, Java converts it automatically.

### Example 1: int → double

```java
int a = 10;
double b = a;

System.out.println(b); // 10.0
```

✔ No data loss
✔ No explicit casting
✔ Happens at compile time

---

### Example 2: byte → int

```java
byte b = 20;
int i = b;

System.out.println(i); // 20
```

✔ Safe
✔ Automatic

---

### Example 3: char → int (Tricky & Interview Favorite)

```java
char ch = 'A';
int value = ch;

System.out.println(value); // 65
```

💡 Explanation:

* Java stores characters as **Unicode values**
* `'A' → 65`

---

### Automatic Conversion Rules

Java allows automatic conversion when:

1. Types are **compatible**
2. Destination type is **larger**

---

### 🚫 Automatic Conversion NOT Allowed

```java
double d = 10.5;
int x = d;   // ❌ Compile-time error
```

## **4. Type Casting (Narrowing Conversion) (20 mins)**

### Definition

When converting **larger data type to smaller**, Java needs **explicit instruction**.

Syntax:

```java
targetType variable = (targetType) value;
```

---

### Example 1: double → int

```java
double d = 10.9;
int x = (int) d;

System.out.println(x); // 10
```

❗ Decimal part is **discarded**, NOT rounded.

---

### Example 2: int → byte (Overflow Case – Very Important)

```java
int a = 130;
byte b = (byte) a;

System.out.println(b); // -126
```

💡 Explanation:

* byte range: `-128 to 127`
* 130 exceeds range → **wraps around**

👉 **Interview Trap**

---

### Formula to Explain Overflow (Trainer Tip)

```
Result = (value % range) + minValue
```

---

### Example 3: char ↔ int

```java
int x = 66;
char c = (char) x;

System.out.println(c); // B
```

✔ Explicit casting
✔ Common interview question

---

## **5. Type Promotion in Expressions (20 mins)**

### MOST CONFUSING PART FOR BEGINNERS (And Interview Gold)

---

### Rule #1: byte, short, char → int

```java
byte a = 10;
byte b = 20;

byte c = a + b;  // ❌ Compile-time error
```

💡 Why?

* `a + b` is automatically promoted to `int`

✔ Correct way:

```java
byte c = (byte)(a + b);
```

---

### Rule #2: Highest type dominates expression

```java
int a = 10;
double b = 5.5;

double result = a + b;
```

✔ int → double
✔ result is double

---

### Rule #3: Mixing char in expressions

```java
char c = 'A';

System.out.println(c + 1); // 66
```

💡 char → int before calculation

---

### Rule #4: Assignment vs Expression (Very Tricky)

```java
byte b = 10;
b = b + 1; // ❌ error
b++;       // ✔ works
```

💡 Why?

* `b + 1` → int
* `b++` has implicit cast built-in

👉 **Interview Favorite**

---

## **6. Casting Incompatible Types (15 mins)**

### Case 1: boolean with numeric types ❌

```java
boolean flag = true;
int x = (int) flag; // ❌ Compile-time error
```

✔ boolean cannot be cast to/from any numeric type

---

### Case 2: Object type casting (Preview – OOP context)

```java
Object obj = "Hello";
Integer i = (Integer) obj; // ❌ Runtime: ClassCastException
```

💡 Compiles, but fails at runtime.

---

### Case 3: Reference type compatibility

```java
Number n = Integer.valueOf(10);
Double d = (Double) n; // ❌ Runtime error
```

---

### Rule for Reference Casting

* Compiler checks **inheritance**
* JVM checks **actual object**

---

## **7. Common Interview Traps & Edge Cases (10 mins)**

### 1️⃣ Loss of precision

```java
long l = 9999999999L;
float f = l;

System.out.println(f); // precision loss
```

---

### 2️⃣ Compound assignment auto-casting

```java
byte b = 10;
b += 5;  // ✔ works
```

💡 `+=` does implicit casting

---

### 3️⃣ Final variables & promotion

```java
final byte a = 10;
byte b = a + 5; // ✔ works
```

💡 Compile-time constant optimization

---

## **8. Summary Table (Very Useful for Students)**

| Scenario           | Allowed | Reason          |
| ------------------ | ------- | --------------- |
| int → double       | ✔       | Widening        |
| double → int       | ❌       | Narrowing       |
| byte + byte → byte | ❌       | Promoted to int |
| char → int         | ✔       | Unicode         |
| boolean ↔ numeric  | ❌       | Incompatible    |
| `+=` on byte       | ✔       | Implicit cast   |
